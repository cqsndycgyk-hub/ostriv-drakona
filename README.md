# Експедиція: Острів Дракона

Перша місія «Де спить дракон?» для дитини 6–7 років. Повністю прохідна: від титулу до туманного острова «Наступна експедиція», з усіма гілками, підказками, збереженням і поверненням після перерви.

Цей файл — для дорослого (PO, батьків, тестувальника). Дитина його не бачить.

---

## 1. Як запустити на комп'ютері

Розпакуйте архів і двічі клацніть `index.html`. Гра відкриється в браузері. Інтернет не потрібен: шрифти лежать у папці `assets/fonts/`.

На комп'ютері прогрес зберігається в браузері для цієї папки. Якщо перенести папку в інше місце, гра почнеться спочатку.

## 2. Як викласти на GitHub Pages (щоб відкривати з телефона)

1. Зайдіть на github.com і створіть новий репозиторій, наприклад `ostriv-drakona`. Тип — **Public**.
2. На сторінці репозиторію натисніть **Add file → Upload files**.
3. Перетягніть **вміст** папки `ostriv-drakona` (а не саму папку): `index.html`, `sw.js`, `manifest.webmanifest`, `README.md` і папки `css`, `js`, `assets`. Натисніть **Commit changes**.
4. Відкрийте **Settings → Pages**. У розділі **Build and deployment** оберіть **Source: Deploy from a branch**, гілка **main**, папка **/ (root)**. Натисніть **Save**.
5. За 1–2 хвилини вгорі сторінки з'явиться адреса вигляду `https://ВАШ-ЛОГІН.github.io/ostriv-drakona/`. Це і є гра.

### Як оновити гру після правок

Завантажте змінені файли тим самим способом (**Add file → Upload files**, файли з тими самими іменами замінять старі).

**Важливо:** після кожного оновлення відкрийте `sw.js` і змініть рядок `var VERSION = 'ostriv-2026-10-26-1';` на будь-яке нове значення, наприклад `...-2`. Без цього телефон, на якому гру вже відкривали, ще деякий час показуватиме стару версію. Навіть зі зміненою версією нова з'являється з **другого** відкриття: перше відкриття завантажує її у фоні.

## 3. Як додати гру на домашній екран iPhone (обов'язково для тесту)

iPhone може стерти збережену гру, якщо сайт не відкривали 7 днів. Іконка на домашньому екрані цього не допускає.

1. Відкрийте адресу гри в **Safari** (не в Chrome).
2. Натисніть кнопку **Поділитися** (квадрат зі стрілкою вгору).
3. Прокрутіть і оберіть **На початковий екран** (Add to Home Screen) → **Додати**.
4. Дитина відкриває гру тільки цією іконкою «Острів Дракона».

На Android (Chrome): меню ⋮ → **Додати на головний екран**.

**Увага:** гра з іконки і гра у вкладці Safari мають **окремі збереження**. Якщо дитина грає з іконки, журнал теж треба відкривати з іконки (див. розділ 5).

## 4. Офлайн-режим

Якщо гру хоча б раз відкрили з GitHub Pages з інтернетом, далі вона працює без інтернету: при вимкненому світлі, в літаку, на дачі. Нічого вмикати не треба.

Офлайн-режим працює лише з адреси `https://…`. При запуску з файлу (подвійним кліком) він не потрібен: файли й так лежать на диску.

## 5. Журнал тестування

Журнал показує, де дитина застрягала. У ньому видно:

- час на кожному епізоді;
- помилки, рівень підказки і натискання [Покажи] на кожному кроці;
- усі варіанти, які дитина пробувала біля річки, і остаточний вибір;
- скільки секунд дитина дивилась на кожен запис щоденника («не читав» — менше 4 секунд);
- «Заночувати» і перерви між сесіями;
- скільки разів дитина тицяла на туманний острів «Наступна експедиція».

**Як відкрити:**

- **У браузері:** допишіть до адреси гри `?log`, наприклад `https://ВАШ-ЛОГІН.github.io/ostriv-drakona/?log`. На комп'ютері: `index.html?log`.
- **З іконки на домашньому екрані** (там немає адресного рядка): натисніть і **тримайте 3 секунди правий верхній кут екрана** (там, де лічильник фрагментів «N/6»). Відкриється журнал.

Кнопка **«Скопіювати як текст»** копіює весь журнал. Вставте його в чат з командою. Кнопка **«Назад до гри»** повертає туди, де зупинилась дитина.

Журнал зберігається на тому самому пристрої, де грала дитина. Почати нову експедицію можна без втрати журналу: він не стирається.

**Головний критерій MVP:** рядок «Тапів на "Наступна експедиція"». Два і більше означає, що критерій пройдено.

## 6. Як почати спочатку

- Після перерви гра показує привітання Мирона. Під жовтою кнопкою є тихе посилання **«Почати нову експедицію»** → **«Так, стерти»**.
- Після фіналу те саме посилання є внизу фінальної карти.

Скидання стирає прогрес, але залишає журнал тестування і лічильник тапів на туманний острів.

## 7. Перевірка будь-якого екрана (для QA)

Допишіть до адреси `?debug`. Відкриється список усіх екранів. Угорі можна обрати, з якої гілки почато (болото чи ліс), що дитина сказала Миронові біля річки і як переходили воду. Натисніть на екран — гра відкриється на ньому з таким станом, ніби все попереднє вже пройдено.

**Увага:** перехід з `?debug` перезаписує прогрес на цьому пристрої. На телефоні дитини не користуйтеся.

## 8. Налаштування і тексти

- **Стать дитини** — файл `js/config.js`, рядок `childGender: 'm'` (`'m'` — хлопчик, `'f'` — дівчинка). Від неї залежать кілька реплік Мирона, наприклад «Як ти це помітив?».
- **Усі тексти і дані задач** — у файлі `js/content.js`. Правити тексти можна там, не чіпаючи решту коду. Після правок перевірте, що лапки й коми стоять на місцях: відкрийте гру, і якщо екран порожній, у файлі синтаксична помилка.

## 9. Будова проєкту

```
index.html             — сторінка гри
manifest.webmanifest   — назва й іконка для домашнього екрана
sw.js                  — офлайн-режим (GitHub Pages)
css/style.css          — кольори, шрифти, розкладка
js/config.js           — стать дитини, режим налагодження
js/content.js          — усі тексти і дані задач
js/art.js              — уся графіка (SVG): Мирон, острів, сцени, дракон
js/state.js            — збереження прогресу (ключ ostriv.v1)
js/ui.js               — шаблони екранів, панель рюкзака, підказки
js/screens.js          — екрани місії за ID зі STEP 3
js/tools.js            — журнал (?log) і список екранів (?debug)
js/main.js             — запуск, переходи, повернення після перерви
assets/fonts/          — шрифти Unbounded, Golos Text, Caveat (ліцензія SIL OFL)
assets/icon-*.png      — іконка для домашнього екрана
```

## 10. Відомі обмеження

- **Приватний режим Safari:** гра працює, але не зберігає прогрес.
- **iPhone SE у звичайній вкладці Safari:** на екранах «запис щоденника + запитання» може знадобитися невелика прокрутка. З іконки домашнього екрана все вміщується.
- Звуку немає. Це рішення MVP.
